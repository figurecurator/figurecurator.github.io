Oshi Atlas 및 RainbowSoft 소개 웹사이트

시행일: 2026년 10월 15일 · 운영자 및 개인정보 문의: RainbowSoft / contact@rainbowsoft.co.kr

1. 적용 범위

이 방침은 RainbowSoft 소개 웹사이트와 Oshi Atlas 플러그인에서 RainbowSoft가 처리하는 정보에 적용됩니다. 별도 앱의 계정·소장 데이터, 판매점 구매, OpenAI 등 연결 플랫폼의 대화 보관에는 각 서비스의 방침이 적용됩니다.

2. 처리하는 정보와 목적

  • 검색 및 도구 입력: 상품·인물·작품 검색어, 상품·엔티티 ID, 결과 페이지 커서 등 요청을 처리하는 데 필요한 입력을 받습니다. 음악·피규어 검색, 상품 정보 조회와 관계 식별에 사용합니다. 플러그인은 대화 전체나 연결 플랫폼 계정 프로필을 입력으로 요구하지 않습니다.
  • 접속 및 장애 정보: 호스팅·보안 제공자가 IP 주소, 요청 URL, 요청 시각, 응답 상태, 오류 및 기술 메타데이터를 처리할 수 있습니다. 요청 처리, 서비스 장애 조사와 보안에 사용합니다. URL에 전달되는 검색어가 로그에 포함될 수 있습니다.
  • 문의 정보: 이메일 주소, 이름 또는 표시 이름, 문의 내용과 직접 첨부한 자료를 문의 응답과 오류 해결에 사용합니다.

현재 소개 웹사이트에는 별도 광고·방문자 분석 스크립트를 넣지 않았습니다. Oshi Atlas에는 이용자 계정이나 개인별 검색 이력 데이터베이스를 두지 않습니다. 요청 처리와 기술 로그 처리는 이에 별도로 해당합니다.

3. 서비스 제공자와 외부 연결

  • Cloudflare: Oshi Atlas MCP와 Discovery API의 요청 처리, 보안 및 기술 로그를 제공합니다. 글로벌 인프라에서 처리가 이뤄질 수 있습니다.
  • GitHub Pages: 이 소개 웹사이트의 호스팅을 제공합니다. 방문 요청과 접속 정보를 처리할 수 있습니다.
  • Figure Curator 및 Discovery API: 기능에 필요한 검색어와 상품·엔티티 식별 정보를 전달해 공개 정보를 조회합니다. Figure Curator는 RainbowSoft가 운영하는 별도 서비스입니다.
  • OpenAI 및 이용 중인 연결 플랫폼: 사용자가 요청한 도구 입력을 RainbowSoft 서비스에 전달하고 결과를 받습니다. 대화 저장과 호스트 웹 검색은 해당 플랫폼이 처리합니다.
  • 메일 제공자: 문의 이메일 전달·보관에 사용됩니다. 문의에 포함한 정보만 처리합니다.

외부 음악·판매점 링크를 열면 해당 사이트의 정책이 적용됩니다. RainbowSoft는 이용자 정보를 광고 목적으로 판매하지 않습니다. 제공자의 처리 조건은 Cloudflare, GitHub, OpenAI에서 확인할 수 있습니다.

4. 보관과 삭제

검색 입력은 요청 처리에 사용하며 Oshi Atlas에서 별도 개인별 이력으로 보관하지 않습니다. 공개 상품·출처 데이터와 검색 응답 캐시는 사용자 계정 데이터와 구분됩니다.

RainbowSoft가 관리하는 장애·보안 로그는 최대 30일 이내 삭제합니다. 현재 Cloudflare Workers Logs의 기본 보관 기간은 요금제에 따라 3일 또는 7일로 이 상한보다 짧습니다. 문제 해결을 위해 별도로 추출한 로그도 30일 상한을 적용합니다. 문의 이메일과 첨부자료는 처리 완료 후 1년 이내 삭제합니다. 삭제 요청이 있으면 필요한 확인 후 더 일찍 삭제합니다.

법적 보존 의무가 적용되는 자료는 필요한 범위와 기간만 보존하며 요청자에게 사유를 안내합니다. RainbowSoft가 직접 통제하지 않는 외부 플랫폼의 보관 기간은 그 제공자의 정책에 따릅니다.

5. 이용자의 선택과 권리

도구 입력에 개인정보나 비밀 정보를 포함하지 마세요. 플러그인 사용을 중단하거나 연결을 해제할 수 있습니다. RainbowSoft가 보유한 개인정보의 열람·정정·삭제 또는 처리 제한을 요청하려면 contact@rainbowsoft.co.kr로 연락해주세요. 보관하지 않은 입력은 나중에 조회하거나 특정 사용자에게 연결할 수 없을 수 있습니다.

6. 보호조치와 변경

서비스 통신에 HTTPS를 사용하고 운영 접근을 필요한 담당자로 제한합니다. 기능과 데이터 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다. 중요한 변경 사항은 이 웹사이트에 안내합니다.
